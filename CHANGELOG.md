# Changelog / 更新日志

English first; Chinese follows below.

## 0.1.0 — 2026-10-24

Initial public package of Adaptive Research Tutor.

- Add the instruction-only Skill and four references for teaching, context/checkpoints, progress, and evaluation.
- Support context-adaptive, one-concept-at-a-time teaching, follow-up questions, detours, and recovery from accessible progress files.
- Keep tutor pacing independent of the main task, with read-only access to engineering files by default.
- Leave learner-background examples empty and document optional per-user input.
- Add an English-first, complete-Chinese README and exclude local validation artifacts and personal learning records.

## 中文更新日志

### 0.1.0 — 2026-10-24

Adaptive Research Tutor 首个公开整理版本。

- 提供纯指令 Skill，以及教学、上下文/检查点、进度和验收四份参考文件。
- 支持上下文自适应、每次一个主要知识点、连续追问、临时跳转，以及从可访问进度文件恢复。
- 教学速度与主任务独立，导师默认只读工程文件。
- 学习者背景示例留空，说明每位用户可以自愿提供自己的背景。
- 增加英文在前、完整中文随后的 README，排除本机验证产物和个人学习记录。
