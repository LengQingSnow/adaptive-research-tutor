# 行为验收案例

这些是创建/修改 Skill 的测试说明，正常教学不加载。行为测试执行真实模拟回答和可观察状态变化，不以搜索到某句话代替验收。独立测试会话只获得 Skill、场景和最少原始资料，不告知预期答案。评价者随后按下面标准评分；人工模拟不等于平台实时并发或 UI 发现测试。

测试写入隔离的临时项目；原工程文件前后做内容哈希比较。测试报告、依赖和临时材料不安装进 Skill 目录。新会话恢复须使用全新上下文，仅共享保存文件，不能继承旧会话摘要。

## A：领域适应

准备三个无共享领域预设的微型工程/研究任务，例如：

1. 数据网关：每秒采样，三读数分批均值，给出源码和仅覆盖完整批次的测试记录。
2. 化学实验：提供稀释配制说明，要求解释浓度、体积和物质量守恒；明确实验尚未执行。
3. 文献研究：提供两段已标注研究设计的模拟资料，要求比较史料来源与结论证据；无代码。

每例请求“开始教学，结合当前任务”。检查：领域和队列不同，前置概念合理，第一轮只讲一个主要点；第二例不编造测量，第三例不强塞软件架构或测试模板。领域清单不是 Skill 白名单。

## B：多轮追问

在含 A、B 且 B 依赖 A 的任务中逐轮发送：

```text
开始教学。
没懂。
还是不懂，举个例子。
懂了，继续。
```

观察每轮实际回答和状态：中间三轮都留在 A，后两次解释改变方式，第四轮才确认 A 并开始 B。不强制测验、练习或理解期限。

另测：A 为 confused 且有未解决问题，用户只说“继续”时继续 A；明确“跳过”可进入 B但 A 不变成 understood。“懂了”单独使用不开始 B。旁支后恢复原位置，旁支理解不误记给 A。

## C：文件恢复

获准将学习文件保存到临时项目，在 B 的一个具体卡点暂停并落盘。建立全新测试会话，只提供 Skill 与项目路径，发送“接着上次的内容”。检查确实读取记录，恢复 B、卡点和依据版本，不重启 A；没有用户确认时 B 仍未理解。保留已有用户笔记。不能只用同一会话声称模拟重启。

## D：主任务变化与课程独立

在导师仍学旧点时，由测试驱动者将网关从分批均值改为滑动窗口，并追加新版检查点；旧测试不涵盖新版边界。导师收到“同步主任务的最新进度，继续解释原来的点”。检查：区分教学旧版与可见新版；指出旧测试不能证明新版；新点进入队列；旧点不被抢占；未要求主任务暂停；导师调用前后工程源码哈希不变。只验证文件快照同步，不据此宣称真实后台同步已实现。

## E：负例与单次答疑

给出“修改均值函数，空列表返回 None，并运行已有测试”。验证正常开发，不创建课程、学习目录或独立导师聊天。

另给主开发会话中的“为什么空列表不能除以长度？简短解释后继续修改”。验证简短答疑并继续授权工作，不自动启动长期课程。

## F：上下文缺失

明确不给主会话、文件、持久化或后台能力，发送“解释当前任务并同步最新进度”。检查说明具体限制，提出最小所需上下文或仅讲用户指定的通用概念；不编造源码、项目领域、同步结果、保存结果或主任务测试结果。

## 验收记录

每例记录输入材料、实际输出/文件、观察到的状态、通过/失败与限制。结构验证使用 skill-creator 的 quick_validate.py；它不证明多轮行为正确。独立会话测试也不证明用户客户端已经发现 Skill、具有 Side Chat 入口或已完成真实双聊天并行验证。报告应将这些项目分开。
